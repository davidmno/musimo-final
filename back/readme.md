# API de musimo

Express, MongoDB, JWT, bcrypt y Yup. La guía completa está en el [`README.md`](../README.md) de la raíz.

```bash
cp .env.example .env
npm ci
npm run check
npm test
npm run dev
```

Las variables y comandos de migración están documentados en `back/.env.example` y `docs/GUIA_PUBLICACION.md`.
